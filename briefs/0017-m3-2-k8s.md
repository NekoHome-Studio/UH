## 需求
### 1. 工作负载（deploy/k8s/ 目录）
- **uh-kernel Deployment ≥2 副本** + readiness/liveness 探针（打 /health、/ready）+ resources requests/limits + **serviceAccountName: uh-scaler**（v0.1.0 复用，决议 E3）。
- **能力模块独立 Deployment**：uh-llama-index / uh-langgraph / uh-crewai，各带探针与 resources。
- **HPA**（autoscaling/v2）：能力模块 CPU 目标 **70%**，min/max 合理；**uh-crewai replicas: 0**（平时不启，按需扩为 1）。
- **StatefulSet + PVC**：redis / chroma / postgres（volumeClaimTemplates，storageClassName 可配）。
- Service：kernel（ClusterIP，供 ingress）+ 能力模块 + 数据存储 headless。
- Namespace **uh-prod**；标签体系 `app: uh-*`、`tier: kernel|capability|datastore`（NetworkPolicy 选择器依赖）。

### 2. 最小 RBAC（严格按 §2 骨架）
- ServiceAccount **uh-scaler**（ns uh-prod）。
- Role **uh-crewai-scaler**：`apps/deployments/scale` resourceNames=[uh-crewai] verbs=[get,patch,update]；`apps/deployments` resourceNames=[uh-crewai] verbs=[get]。
- RoleBinding 绑定二者。**禁止**：cluster-admin / 任何 ClusterRole 绑 uh-scaler / secrets 读写 / pods/exec / RBAC escalate·bind / 通配符 `*` / 跨 ns。

### 3. NetworkPolicy（按 §3 矩阵补全 7 条）
default-deny(Ingress+Egress) / allow-dns(53 UDP+TCP → kube-system kube-dns) / kernel-ingress(仅 ingress-controller ns → kernel 8080) / capability-ingress-from-kernel(tier=capability ← app=uh-kernel:8080) / kernel-egress-capabilities / kernel-egress-datastores(6379/8000/5432) / capability-egress-datastores(langgraph→redis+pg、llama-index→chroma) / llm-egress(kernel+crewai → 外部 443)。

### 4. scaler 数值约束 + 审计（RBAC 表达不了的部分）
`kernel/scaler.py`（或扩展现有模块）：调用 K8s API 扩缩 uh-crewai，**代码强制** replicas ∈ {0,1}、目标仅 uh-crewai、超时放弃；发审计事件（含 trace_id、目标、replicas、结果）。无集群时优雅降级（返回 degraded，不崩）。

### 5. 静态校验门禁（无需真集群）
`scripts/verify-k8s-manifests.mjs`：解析 deploy/k8s/*.yaml 断言——
- kernel replicas≥2 且有探针 + serviceAccountName=uh-scaler；crewai replicas=0；HPA cpu 70%
- RBAC：无 ClusterRoleBinding 涉及 uh-scaler、无 `*` 通配、无 secrets/pods/exec/escalate/bind、resourceNames 恰为 [uh-crewai]、verbs 恰为规定集合
- NetworkPolicy：存在 default-deny 且 policyTypes 含 Ingress+Egress；7 条放行齐全
- 无明文密钥（password/token/key 字面值）
接入 verify-all 新增 **J 项**（保持既有 9 项不变）。

### 6. 测试
`tests/unit/test_k8s_manifests.py`：上述断言的 pytest 版 + scaler 数值约束单测（replicas=2 拒绝、目标非 crewai 拒绝、超时放弃、审计事件发出）。**不需要真集群**。
