## 六、已知坑（长期记忆）
1. Python urllib/httpx 的 Authorization 头被 DSH 环境掩码致 401 → 探针用 ?token= 或 curl（浏览器 fetch 头正常）。
2. 服务器 WS 须 uvicorn[standard]（websockets/wsproto），纯 uvicorn 拒 WS upgrade。
3. REST query-token 须设 owner_token（send_message/dev_tool_task），否则 WS/confirm 归属校验失败。
4. pip 须 NO_PROXY=* + 清华镜像（系统注册表失效代理）。
5. 进程常驻须 WMI（SSH 会话结束杀子进程）。
6. 本机 C: 空间紧张（~58GB），大文件优先 D:。
