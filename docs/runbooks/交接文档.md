## 8. 已知坑（长期记忆）
1. Python urllib/httpx 的 Authorization 头被 DSH 环境掩码致 401 → 探针用 ?token= 或 curl（浏览器 fetch 头正常）。
2. 服务器 WS 须 uvicorn[standard]（websockets/wsproto），纯 uvicorn 拒 WS upgrade。
3. REST query-token 须设 owner_token（send_message/dev_tool_task），否则 WS/confirm 归属失败。
4. owner_matches 双因子：client_id 自 asserted 可 spoof，完全隔离需 per-user principal。
5. pip NO_PROXY=* + 清华镜像；进程常驻 WMI；本机 C: 空间紧张大文件优先 D:。
6. 密钥严禁入仓库/命令行/日志（四审 P0-1 教训）；secret 扫描门禁已加。
7. TestClient 进程内模拟 WS，跨机须真实 websockets 验证；跨机探针需 client_id 贯穿。
