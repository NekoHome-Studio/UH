## 8. 已知坑（长期记忆）
1. **提交≠部署**：代码提交后须同步服务器并重启，否则跨机验收结论不可信（M2/M3 各踩一次）。
2. **scp 通配符静默失败**：`deploy/x/*.yaml` 看着成功实际没传；大目录用 tar 打包。
3. **SFTP 传 Windows 路径**需逐级 mkdir（`D:/uh/deploy/k8s`）。
4. **tests 引用 deploy/desktop/docs 文件**，同步代码必须连支撑目录一起传。
5. Python urllib/httpx 的 Authorization 头被 DSH 环境掩码致 401 → 探针用 `?token=` 或 curl。
6. **query token 必须 URL-encode**（base64 的 `+` 会被解析成空格致 401）。
7. 发消息须带 `client_id`（五审双因子），否则 USR-1002。
8. 服务器 WS 须 `uvicorn[standard]`（含 websockets）。
9. **verify-all 各项是精确白名单**：新增 K8s 资源/NetPol 必须同步 `resources` 表与 `checkNetwork` 期望。
10. **WSL LxssManager 会卡 StopPending**（taskkill 拒绝、sc start 1056）→ 只能重启；WSL 内 sshd 无法脱离会话常驻。
11. Kylin 无 root：podman 卡 `newuidmap`（需 setuid）；但 **bwrap 可用**，`SandboxRunner.enforce=True`。
12. Codex **非零退出未必是半成品** —— 先跑门禁 + 查交付完整性再判断（M3-6 实例）。
