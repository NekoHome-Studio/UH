## 本轮验证

- Chrome 通过本机回环地址切换官方浅色示例。从选择框 `change` 事件到读取到新计算样式，5 次耗时分别为 21.4、24.6、23.8、25.4、9.3 ms。重新加载页面后，背景色、8 px 圆角和 16 px 间距均恢复。独立的签名包回归测试使用新应用实例确认内核重建后保留选择。
- 主题资源仅允许 `assets/preview.png` 和与 `font_stack` 对应的包内 WOFF2。安装前检查资源声明大小，单个资源最多 2 MiB，合计最多 8 MiB。Web 使用 REST 选取主题，选择记录保存在插件注册表旁。主题 REST 接口待项目评审后登记到冻结 OpenAPI 的后续版本。
- 官方源码的 CLI 校验在本地开发模式显式启用 `--no-verify`。Ed25519 验签由签名包回归单独覆盖，发布包继续使用默认签名策略。
- `python -m pytest -q` 通过 195 项。`node scripts/verify-all.mjs` 通过 6/6，`--full` 通过 8/8，`git diff --check` 通过。
