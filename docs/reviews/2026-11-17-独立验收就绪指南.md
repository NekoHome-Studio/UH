## 三、生产链路端到端验收脚本（建议）
1. 鉴权：UH_LOCAL_MODE=0 + UH_AUTH_REQUIRED=1 + token；无凭据请求业务端点（含别名）全 401，ops 200。
2. WS 实时流：带 token 建任务 → 收 task.created→delta→task.finished，event_id 连续；中途断线重连按 after_event_id 不丢。
3. 工具确认（inline）：create_tool_task irreversible → task.confirmation_required → POST /confirm approved → tool.call/result → finished；rejected → cancelled。
4. 工具确认（RPC）：register_capabilities irreversible 工具经 RPC → fail-closed USR-1002 不执行。
5. 取消：运行中任务 POST /cancel → step.failed 闭合 + task.cancelled；终态再 cancel → 409。
6. 超窗回退：任务超 5min 窗口重连 → 4408 → GET /steps 全量阶段（含 task_id）。
7. 跨客户端隔离：多用户模式不同 caller 幂等键不复用；任务归属校验。
8. 隐私：L3 拒入（含 override）；L2 加密不语义索引；无痕不写长期。

## 四、已知设计局限（非缺陷，验收时知悉）
- **REST 完全多用户隔离**：当前单共享 UH_AUTH_TOKEN（单用户+口令模型）。_task_guard/WS 重校结构正确，但完全 per-user 隔离需独立 principal 鉴权设计（未来项）。验收时以「单共享 token 下别名/默认值/归属守卫生效」为准。
- **记忆 scope 默认 global**：用户 ADR-003 裁决（session 可选），非缺陷。
- **4004 retryable**：errors.md 默认 true，服务端按场景判定（契约允许 retryable 服务端裁定）。
