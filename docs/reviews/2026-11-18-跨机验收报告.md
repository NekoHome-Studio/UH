## 跨机验收发现并修复的问题

| 问题 | 根因 | 修复 |
|---|---|---|
| WS upgrade 被拒（事件流断开） | 服务器 uvicorn 缺 websockets 库（本地 TestClient 进程内模拟故测试绿） | 装 websockets；pyproject uvicorn[standard] |
| WS 订阅 USR-1002 | REST ?token= 未设 owner_token（只认 Authorization 头），WS 归属退化 client_id 比对失败 | send_message owner_token 也取 query token |
| 跨机 confirm USR-1002 | dev_tool_task 未设归属（同 send_message 问题） | dev_tool_task 设 owner_token+client_id |
| UI 创建会话 401 | 生产鉴权下 UI 未带 token | UI 鉴权层（token 输入框+URL/localStorage+withToken） |

## 环境坑（记入长期记忆）
- Python urllib/httpx 的 Authorization 头被 DSH 环境掩码致 401；跨机探针用 ?token= 查询或 curl（浏览器 fetch 头不受影响）。
- 服务器 WS 须 uvicorn[standard]（含 websockets/wsproto）。

## 未跨机项（本地单测覆盖）
- 确认超时（TTL 300s 固定，跨机等待过长；本地 ttl_s=1 单测覆盖）。
- RPC fail-closed（内部 RPC，非 HTTP；本地单测覆盖）。
- 超窗回退（需服务器等 5min 或操纵时间；本地单测覆盖）。
- L3/L2 隐私（无公开写入口；本地单测覆盖）。
- WS  mid-stream 重连不丢（mock LLM 快终态；本地单测覆盖）。
