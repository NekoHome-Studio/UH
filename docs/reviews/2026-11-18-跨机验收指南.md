## 二、验收模式
### A. 本地豁免模式（服务器当前默认）
服务器未设 UH_AUTH_REQUIRED → 业务端点免鉴权（单用户本地）。适合功能链路验收。
### B. 生产鉴权模式（跨机验收推荐）
服务器设环境变量后重启（WMI）：
```
UH_LOCAL_MODE=0  UH_AUTH_REQUIRED=1  UH_AUTH_TOKEN=<强随机token>
UH_PUBLIC_BASE_URL=http://192.168.0.28:8080   # stream_url 输出 ws://192.168.0.28:8080/...
```
重启脚本：ssh ipc "powershell -File D:\uh\start-uh.ps1"（需先设系统环境变量或改启动脚本注入）。
验收机请求带 Authorization: Bearer <token>（或 ?token=）。

## 三、跨机生产链路验收项（curl/python 从验收机发）
1. **鉴权**（模式 B）：无 token POST /api/v1/sessions → 401（meta.trace_id 非空）；别名 /memory/export、/plugins 无 token → 401；ops /health → 200；带 token → 201。
2. **会话存在性**：POST /api/v1/sessions/uh_ses_unknown/messages → 404 USR-1003。
3. **WS 实时流**：python websocket 连 ws://192.168.0.28:8080/api/v1/stream?task_id=<id>&token=<tok>，收 task.created→delta→finished，event_id 连续；断线 after_event_id 重连不丢。
4. **工具确认 inline**：dev/tool-task（irreversible）→ confirmation_required → POST /confirm approved→finished / rejected→cancelled / 超时→timeout。
5. **工具确认 RPC**：irreversible 工具经 RPC → fail-closed USR-1002 不执行（tool.call→tool.result(denied) 配对）。
6. **取消**：运行中 POST /cancel → step.failed 闭合 + cancelled；终态再 cancel/resume → 409。
7. **超窗回退**：超 5min 重连 → 4408 → GET /steps 含 task_id 全量（step_log 永久）。
8. **隔离/隐私**：跨客户端幂等不复用、无 Set-Cookie 泄漏；L3 拒入（含 override）；L2 加密不语义索引。
9. **UI**：浏览器开 http://192.168.0.28:8080/ → 确认弹窗/重连/degraded 徽标/aria-live。

## 四、跨机特别注意
- **网络延迟**：WS 重连退避（500ms×2^n）在跨网延迟下仍有效；验收断线重连不丢事件。
- **Host 头**：stream_url 用 UH_PUBLIC_BASE_URL（可信），不信任请求 Host（防注入）；跨机经代理时验收 stream_url 不含代理 Host。
- **防火墙**：服务器 8080 入站规则已加（server-deploy.ps1）；验收机连不通先查防火墙。
- **探针隔离**：远程探针无法设服务器存储 env，验收用独立会话/任务，避免污染服务器运行态；清库类探针（DELETE /memory/long-term）慎用。
- **token 传输**：跨机用 ?token= 会进 URL 日志，生产建议 Authorization 头；验收两种都测。
