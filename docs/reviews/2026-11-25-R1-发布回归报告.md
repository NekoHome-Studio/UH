## 6. 未达标项（如实披露，不阻断发布）

### #36 P95 SLO
| 指标 | 目标 | 实测（Kylin 4worker+Redis） | 判定 |
|---|---|---|---|
| 错误率 | <1% | **0%（三场景）** | ✅ **达标** |
| P95 | ≤2000ms | chat 6.7s / search 7.2s / orchestrate 6.9s | ❌ 未达标 |

**相对最初基线改善 8~9 倍**（search 55.8→7.2s、orchestrate 62.6→6.9s）。

**根因（已诊断）**：单进程内请求提交与任务执行共享事件循环，无法真正隔离。
六轮优化（线程池卸载 / embedding 缓存 / 倒排索引 / delta 不入总线 / 长记忆 offload / 有界执行闸）
已把可控部分做到极限。突破需**独立执行进程池**（任务记录 + 事件 pub/sub 重构），
属独立架构工程，建议 M4 / v0.2.0 立项。

详见 `docs/reviews/2026-11-25-延迟根因诊断.md`。
