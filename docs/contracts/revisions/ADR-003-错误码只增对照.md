# ADR-003 错误码只增修订对照（UH-CAP-4004）

- 日期：2026-11-17 · 状态：已应用（用户裁决「两个都做，用户/插件自由切换」）
- 性质：**只增不改**——新增 UH-CAP-4004 行，UH-CAP-4003 原行与原义不变。

## 新增（errors.md §2 表）

| 错误码 | 含义 | HTTP | retryable | detail |
|---|---|---|---|---|
| UH-CAP-4004 | 能力模块执行错误（MCP/编排/插件，ADR-003 只增） | 502 | true | module 必填 + tool_name/node_id；UH_CAP_ERROR_MODE=legacy 回退 CAP-4003 |

## 语义边界
- UH-CAP-4003：保持冻结原义＝LLM 上游服务错误（llm.py 专用，不受模式影响）。
- UH-CAP-4004：能力模块（MCP 传输/工具、编排节点、protocol 模块 handler）执行错误。
- UH_CAP_ERROR_MODE=strict（默认）模块错误→4004；legacy→4003（兼容旧插件/前端文案）。

## 实装调用点
- kernel/protocol.py module_error_code() 助手 + CapabilityRegistry.call 模块异常。
- kernel/mcp.py 全部 MCPError 模块错误路径。
- kernel/orchestration.py OrchestrationError + step.failed。
- kernel/tasks.py 编排通用异常分支（并修异常消息透传）。

## 记忆召回范围（同批 ADR-003，非错误码）
- UH_MEMORY_SCOPE=global（默认，跨会话）/ session（本会话隔离）；context.memory_scope 每请求覆盖。
- 写入恒标 session_id，scope 仅影响召回过滤；两模式共用存储。
