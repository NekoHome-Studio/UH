## R1 任务归属凭据

生产鉴权模式下，`client_id` 不再接受调用方直接提交的裸字符串。服务端通过 HMAC 签发客户端归属凭据，凭据可经 HttpOnly `uh_client_id` Cookie、`X-UH-Client-ID` 请求头或 WebSocket `client_id` 查询参数携带。服务端校验签名后，将其解析为任务归属主体。

部署环境应通过 `UH_CLIENT_ID_SECRET_FILE` 或 `UH_CLIENT_ID_SECRET` 提供稳定密钥。未配置时实现使用进程级随机密钥，适用于当前内存任务模型，不适合作为多进程持久化部署配置。

本地模式保留会话级兼容值，便于单机开发。任务创建、REST 任务守卫、SSE、WebSocket 和幂等 caller 共用同一解析顺序，显式签名 Header 优先，其次 Cookie，最后查询参数。

## R2 终态回连

终态任务的热事件缓冲会释放 `delta`。终态回连返回终态快照并以 close `1000` 结束，不将已释放的中间事件伪装成可回放数据。完整答案由 `task.finished.payload.final_result.content` 承载。

## R3 密钥扫描

密钥扫描使用 `git ls-files` 覆盖所有受版本控制的文本文件，匹配 `UH_AUTH_TOKEN` 的空格、引号和 YAML 冒号写法。扫描逻辑提供正负例回归，避免扫描器自身失效。

## R4 生产门禁

M1 五审附条件项仍需部署侧收敛，包括关闭 `UH_DEV_MODE`、TLS 与 WebSocket 短时票据、服务器测试和契约文件同步，以及 verify-all 子进程 stderr 保留。
