## 任务

- [x] 为扩缩容定义独立 ServiceAccount + 最小 RBAC（仅 get/patch 指定 Deployment 的 replicas）
- [x] 该权限约束写入 9.2 认证与凭据管理 / 9.3 插件沙箱安全
- [x] 补 K8s NetworkPolicy：能力模块仅允许内核与必要依赖访问

## 验收标准
- [x] Compose 外网仅暴露 8080
- [x] RBAC 权限清单可审计，无 cluster-admin
- [x] NetworkPolicy 默认拒绝、按需放行
